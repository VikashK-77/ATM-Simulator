# ATM Simulator

A simple console-based ATM Simulator built using Core Java fundamentals.

## 📌 Project Overview

This project simulates basic ATM operations through a command-line interface. It was built as a beginner Java project to practice programming fundamentals and logical problem-solving.

## 🚀 Features

- Deposit money
- Withdraw money
- Check account balance
- Validate deposit and withdrawal amounts
- Handle insufficient balance
- Handle invalid menu choices
- Exit the ATM safely

## 🛠️ Technologies Used

- Java
- IntelliJ IDEA

## 📚 Java Concepts Used

- Variables and Data Types
- Scanner for User Input
- if-else Statements
- switch-case
- while Loop
- break and continue
- Basic Arithmetic Operations

## ▶️ How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA or any Java IDE.
3. Open `src/ATM.java`.
4. Run the program.
5. Follow the instructions displayed in the console.

## 💡 Sample Operations

The user can:

- Deposit money into the account
- Withdraw money if sufficient balance is available
- Check the current balance
- Exit the application
